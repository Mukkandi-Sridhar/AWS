Lab 02
VPC + Web Server
Build a private network on AWS and launch a publicly accessible web server.
VPC · EC2
Step-by-Step Walkthrough
  1. Use the VPC and more wizard — name lab, one AZ, one public + one private subnet. AWS auto-creates the VPC, Internet Gateway, and NAT Gateway.
  2. Manually add lab-subnet-public2 and lab-subnet-private2 in a second AZ.
  3. Link each subnet to the correct route table (public → public table with IGW, private → private table with NAT).
  4. Create security group Web Security Group — inbound HTTP (port 80) from 0.0.0.0/0.
  5. Launch EC2 Web Server 1 — Amazon Linux, t2.micro, placed in lab-subnet-public2, attach Web Security Group, paste User Data script.
  6. After 2/2 status checks pass, copy the public DNS name and open it in a browser.

EC2

Lab 04
Elastic Block Store (EBS)
Create a volume, write a file, snapshot it, delete the file, restore from snapshot.
EBS
Step-by-Step Walkthrough
  1. Note the Lab instance's Availability Zone (e.g. us-east-1a). Create a 1 GiB gp2 volume named My Volume in that same zone.
  2. Attach My Volume to Lab instance as /dev/sdf.
  3. Connect via EC2 Instance Connect. Format the disk, create /mnt/data-store, mount it, add entry to /etc/fstab.
  4. Write file.txt to /mnt/data-store.
  5. Create a snapshot named My Snapshot from My Volume.
  6. Delete file.txt. Create a new volume from the snapshot, attach as /dev/sdg, mount to /mnt/data-store2 — file is restored.

Lab 06
Auto Scaling + Application Load Balancer
Distribute traffic and automatically add servers when CPU exceeds 60%.
ELB · ASG · CloudWatch
Step-by-Step Walkthrough
  1. Create AMI WebServerAMI from existing Web Server 1.
  2. Create Target Group LabGroup (type: Instances, VPC: Lab VPC).
  3. Create Application Load Balancer LabELB — public subnets, Web Security Group, forward HTTP → LabGroup.
  4. Create Launch Template LabConfig — WebServerAMI, t2.micro, vockey, Web Security Group, CloudWatch detailed monitoring.
  5. Create ASG Lab Auto Scaling Group — private subnets, attach LabGroup, desired 2 / min 2 / max 6. Tag: Name=Lab Instance.
  6. Scaling policy: target tracking, Average CPU 60%. Click Load Test in the app. Watch AlarmHigh trigger and new instances launch.
